# 🌿 Grovia

**Grovia** is a modern, responsive web application designed with a focus on clean aesthetics, intuitive navigation, and a smooth user experience. The project combines a simple interface with engaging visual elements to create a pleasant and user-friendly web experience.

## ✨ Features

* 🎨 Clean and modern user interface
* 📱 Fully responsive across different screen sizes
* ⚡ Smooth and interactive experience
* 🧭 Simple and intuitive navigation
* 🖼️ Visually engaging layouts and components
* 🌐 Hosted using GitHub Pages

## 🛠️ Tech Stack

* **HTML5** – Structure and content
* **CSS3** – Styling, layouts, and responsiveness
* **JavaScript** – Interactivity and functionality
* **GitHub Pages** – Deployment
